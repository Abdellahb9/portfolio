// About Me

Get to know me

Where I am, and what I have built so far.

I'm in my final year of software engineering at Universiapolis in Laayoune, on the AI and data analysis track. I graduate in 2027.

Most of what I know came from building things rather than sitting in lectures. The parking platform is the clearest example. I designed the MongoDB schema, wrote the Express API with three separate user roles, then built the React dashboard on top of it and a Flutter app for drivers.

The attendance system was a different kind of problem. Face recognition is easy to demo and hard to make dependable, so most of the work went into enrollment and sample quality rather than the matching itself. During my internship at Janoub Innovations Group I built an enterprise inventory platform, and in a distributed-systems lab I got hands-on with Spark, Kafka and Hadoop.

Outside code, I mentor young students in robotics and science workshops — I led sessions at the Oriental Science Festival in Oujda. After this degree I want to keep studying, probably in Germany or France.

Featured work

Six things I've built. All the code is on GitHub.

FULL-STACK PLATFORM
Web + Mobile

AutoPark — Smart Parking Management

Three apps that work together. An Express API on MongoDB, a React dashboard with a live Leaflet map, and a Flutter app for drivers. Admins, parking owners and technicians each get their own view of the system. It handles bookings, complaints, fines and a points scheme for regular users.

Node.js Express MongoDB JWT React Tailwind Leaflet Flutter

COMPUTER VISION
Python

Smart Biometric Attendance System

Takes attendance from a webcam. MediaPipe finds the faces, dlib turns each one into an embedding, and those get matched against students enrolled beforehand. Enrollment grabs 15 to 25 samples per person and discards the poor ones. The dashboard is Streamlit.

Python MediaPipe dlib OpenCV NumPy Streamlit
View on GitHub
3D FRONTEND
React + TypeScript

Bueno — Restaurant Website

A site for a fast food place in Laayoune. The burger in the hero is 3D, built out of basic shapes in React Three Fiber instead of a model file. Menu and review data sits in typed files so it can be swapped for a real API later.

React 18 TypeScript Vite Tailwind React Three Fiber Drei Framer Motion
